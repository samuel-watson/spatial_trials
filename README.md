# Code to reproduce the results of Watson and Smith (2025)

## What's included?
Clone the repository to run the analyses. The src/ folder includes a variety of functions to generate various analyses, including some written in C++ requiring compilation through 
Rcpp. There are four key files at the top level of the repository:
- _continuous_simulation.R_ This file runs a simulation for a point-source intervention with the locations randomised to one of the discrete observation locations
  generated by the simulation. The top of the file loads relevant packages and functions. The next part of the code (lines 22-28) allows the user to set the
  simulation parameters. The user has the option to load pre-generated data (to replicate the article simulation) or generate new point locations and latent surface.
  A source file is then called that will run and print the simulation.

- _discrete_simulation.R_ This file is structured the same as continuous_simulation.R above, and simulates a trial with an area based intervention with either one-way or two-way
  treatment effect functions.
  
- _binka_reanalysis.R_ This file will run the various tests and model fits described in the article for the re-analysis of the data from Binka, Indome, and Smith (1998). This file
  can generate Figure 3 and Figure S4 as well as the results that appear in Table 2.

- _fn_plot.R_ This file will generate Figure S2 in the Supplementary Information, which shows the shape of different versions of the dose response function discussed
  in the article.

## Generating a simulation
The two simulation files contain a block to specify the desired simulation parameters:
```
#SIMULATION PARAMETERS
beta <- 0 # max absolute intervention effect
del_e <- max_dist <- 0.2 # delta -E
del_i <- 0.1 # ignore if using one-way model
n_locs <- 8 # number of intervention sites
radius <- 0.2 # radius of intervention areas
n_seed <- 10 # number of seed locations for observations
n_child <- 150 # number of children per seed
cov_pars <- c(0.25,0.5) # G.P. variance, length scale
max_del <- max_de(n_locs) # upper bound on del_e
adjust <- TRUE # whether to adjust the analysis
oneway <- TRUE # whether a two-way or one-way spillover model, one-way is external only
misspec <- FALSE # if true then the simulation model is a different function to the analysis model
sim_two <- FALSE # if true and oneway is true, then the simulation model will be two way, while model fitting is oneway
n_iter <- 1000 # number of simulation iterations
n_perm <- 1000 # number of permutation test/ bootstrap iterations
print_fit_progress <- TRUE # if true it will print the intermediate model fitting steps
```
These values should be set first, and then the whole script run to start the simulation. Some pre-generated observation locations and latent field are saved 
in the repository and can be automatically loaded if required. Note that the simulation is long-running as model fitting is relatively slow. Code described in the files in the src/ 
folder provides the specific estimators, which can be called independently.
